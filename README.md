# Family Emergency Contact and Important Document Organizer

## Project Overview

The Family Emergency Contact and Important Document Organizer is a Python-based desktop application developed as part of the Indian AI Mission program at iBase Institute.

The main purpose of this project is to help users organize important family emergency contact details and document information in one place.

## Features

- Store and manage family emergency contact details.
- Organize important document information.
- Provide a simple and user-friendly graphical interface.
- Save application data in an Excel file.
- Make information easier to manage and access.

## Technologies Used

- **Programming Language:** Python
- **GUI:** Tkinter
- **Data Storage:** Excel
- **Python Library:** OpenPyXL

## Project Objective

The objective of this project is to develop a simple and useful desktop application that helps users manage family emergency contacts and important document records efficiently.
